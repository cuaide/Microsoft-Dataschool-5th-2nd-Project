## 3. Introduction
The Problem: Raw game statistics (like kills, deaths, and CS) require users to figure out how to translate those numbers into actionable improvements on their own.   
The Solution: The project compares a player's data against others in the exact same tier and position to provide personalized improvement priorities based on their specific playstyle.   
Grounded Answers: When the system answers game-related questions, it finds and attaches official documentation as evidence.   
Project Scope: The creators clarify that they are not claiming to be the first to invent these features, but rather that this was the specific analytical gap they chose to tackle for this project.
